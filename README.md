# Seven-qubit robust extremal marginal count

**Chain.Ren · Independent research · 2026-11-27**

For any pure seven-qubit state, at most 32 of its 35 three-qubit marginals can have normalized purity defect $8\operatorname{Tr}\rho_A^2-1\le1/2500$. A graph state attains all 32 exactly. The resulting finite-error plateau strengthens the known zero-error count; it does not claim the optimal radius.
